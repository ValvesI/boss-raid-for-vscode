# Boss Raid

Boss Raid transforma uma sessao de programacao em uma batalha cooperativa. Crie uma sala, envie o codigo para seus amigos e cause dano no boss ao escrever no editor.

## Como jogar

1. Instale a extensao e clique no icone **Boss Raid** na barra esquerda do VS Code.
2. Digite seu nome e escolha **Criar raid**. Compartilhe o codigo mostrado na sala.
3. Seus amigos instalam a mesma extensao, digitam o nome e o codigo em **Entrar na raid**.
4. Programe normalmente. O progresso no codigo envia ataques ao boss para todas as pessoas da sala.

O servidor publico ja vem configurado. Nao e necessario abrir terminal, executar servidor ou alterar configuracoes para jogar.

## Configuracao

`bossRaid.serverUrl` permite trocar o servidor multiplayer, caso a equipe tenha outro servidor compativel.

## Limitacoes atuais

As salas ficam guardadas temporariamente no servidor. Se o servidor gratuito reiniciar, sera preciso criar outra raid.
